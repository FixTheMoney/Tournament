# 🏆 トーナメント表 自動生成アプリ

参加人数を入力するだけで最適なトーナメント表を自動生成・描画するWebアプリケーションです。管理画面（admin）と投影用ページ（display）の2画面構成で、リアルタイム同期に対応しています。

---

## 📌 機能一覧

### ✅ 実装済み機能

| 機能 | 概要 |
|------|------|
| トーナメント表の自動生成 | 2〜64人に対応。2のべき乗以外はシード枠を自動配置 |
| シード（BYE）均等分散 | 特定選手が有利にならないようシード枠をバランス配置。BYE（不戦勝）の対戦枠自体はブラケット上に表示せず、シード選手は自動的に勝ち上がった次のラウンドから表示される |
| 左右収束レイアウト | 左右の山から中央の決勝へ収束する定番ブラケット表示 |
| 優勝者バナー（ラウンドラベル行の下に表示） | ラウンドラベル（準決勝・決勝など）の行のすぐ下、ブラケット本体の上に🏆優勝者を大きく表示。優勝者が決定していない間はスペース自体を確保せず、バナー（プレースホルダーも含めて）は一切表示しない。優勝が決まった瞬間に自動的に表示される |
| 3位決定戦 | 参加人数4人以上の場合、準決勝敗者同士の3位決定戦を決勝の下に自動追加 |
| 参加者名の入力・反映 | 最大20文字、EnterキーでNext入力に移動 |
| 参加者カテゴリーの入力・反映 | 各参加者名の下にカテゴリー（例：hiphop、lock、popなど）を入力できる任意入力欄を追加。最大20文字。ブラケット内では**デフォルトで名前の直後・同じ行**に「名前 (hiphop)」のように括弧付きで小さめのフォントで表示。名前とカテゴリーを合わせた表示幅がプレイヤー枠の幅に収まらない場合は自動的に2行表示（1行目：名前／2行目：カテゴリー）にフォールバックし、フォントサイズも縮小して枠内に収める（Canvas 2Dの`measureText`によるピクセル単位の実測に基づく自動判定） |
| カテゴリー表示のON/OFFトグル | デザインパネルのプリセットボタンのすぐ下に「カテゴリーを表示する」チェックボックスを配置。オフにすると入力済みのカテゴリーデータを保持したままブラケット上の表示のみを非表示にできる（デフォルトはON）。管理画面・投影画面の両方に反映される |
| 大会タイトル表示 | ブラケット（SVG）上部中央に大会名を表示（ページ上部ヘッダーには何も表示せず、タイトルの二重表示や参加人数・ラウンド数などの余分なメタ情報表示を回避）。タイトルの上下・ラウンドラベル行・優勝者バナーの間には自然な余白を確保し、詰まりすぎず窮屈にならないよう配置 |
| 勝者選択・反映 | 枠クリックでモーダルを表示し勝者を選択（3位決定戦も対応） |
| 勝ち上がり視覚化 | 勝者枠の強調表示・接続線のグロウエフェクト |
| 結果リセット | 個別試合の結果リセット / 全体リセット |
| カラープリセット | シンプルなライト・ダークの2種をワンタッチ選択。プリセットボタンはデザインパネル上部に配置。<br>ライト：背景`#faf2cc`／プレイヤー枠色`#faf2cc`（背景と同色）／枠線`#000000`／文字`#000000`／接続線`#000000`／勝者枠色・勝者接続線色`#c6504c`<br>ダーク：背景`#000000`／プレイヤー枠色`#000000`（背景と同色）／枠線`#ffffff`／文字`#fdfdfd`／接続線`#ffffff`／勝者枠色・勝者接続線色`#c6504c` |
| 詳細色設定（開閉式） | 「詳細設定」を展開すると、背景色・背景の透過度・プレイヤー枠の色・プレイヤー枠線の色・プレイヤー枠線の太さ・勝者枠の色・勝者接続線の色・文字色・BYE文字色を個別に微調整可能（プリセット選択後の微調整用で、デフォルトでは折りたたまれている） |
| プレイヤー枠の境界線カスタマイズ | プレイヤー枠を常時囲む境界線の色と太さ（0〜6px）を個別に調整可能。プレイヤー枠の塗り色が背景色と同色になっても境界線で枠の位置を判別できる |
| 勝者強調色の分離 | 勝者になった枠の背景色（勝者枠の色）と、勝ち上がりを示す接続線の色（勝者接続線の色）を別々に設定可能 |
| 文字サイズの拡大 | 遠くからでも見やすいよう、タイトル・優勝者バナー・ラウンドラベル・各プレイヤー枠の文字サイズを全体的に拡大 |
| 接続線の太さ強化 | プレイヤー枠を繋ぐブラケットの接続線を太く（通常線2.5px、勝者強調線4px）し、遠くからでも視認しやすく改善 |
| プレイヤー枠の拡大 | プレイヤー枠の高さを従来比 約+25%（46px→58px）に拡大し、選手名をより大きなフォントで表示できるように改善。名前とカテゴリーを合わせた表示幅が枠に収まる場合は名前フォントサイズ20px・カテゴリー14px（同一行）、収まらず2段フォールバックした場合は名前18px・カテゴリー13pxで自動調整される |
| 投影画面の表示幅固定 | デザインタブで投影画面(display.html)のトーナメント表の表示幅(400〜3000px)を固定指定可能。オフの場合は画面サイズに自動フィット |
| 画像・ロゴの挿入（ドレグ＆リサイズ対応） | 大会ロゴや協賛ロゴなどの画像をアップロードし、ブラケット上でマウス/タッチにより自由にドレグ移動、右下ハンドルでリサイズ可能。前面/背面（透かし）のレイヤー切換や不透明度調整、複数枚追加・削除も可能 |
| 投影用ページ | フルスクリーン対応の別画面表示 |
| リアルタイム同期 | BroadcastChannelでadmin→displayをリアルタイム更新 |
| ズーム機能 | 投影ページでピンチ/ホイール/ボタンズーム対応 |
| データ永続化 | LocalStorageへ自動保存・再読み込み時も復元 |
| 管理画面のトーナメント表 自動フィット表示 | 管理画面（index.html）のトーナメント表エリアは、画面内に収まる最大サイズまで自動的に拡大／縮小して表示（投影画面と同じ仕組み）。表がエリアより大きい場合は表示エリア内でスクロールして全体を確認可能。ウィンドウリサイズ時にも自動で再フィット |
| ページ背景設定 | トーナメント表の周囲（背後のエリア全体）の背景色・背景画像を管理画面「ページ背景」パネルで設定可能。画像は必要なサイズに合わせて引き伸ばされて（縦横比を無視してエリア全体を埋めるように）表示。管理画面(index.html)・投影画面(display.html)の両方に反映され、リアルタイム同期対象 |
| 対戦者名のフォント・太字設定 | 「デザイン」パネルの「詳細設定」内で、対戦者名（プレイヤー名）に使用するフォントをGoogle Fontsの8種類（Noto Sans JP／M PLUS Rounded 1c／Kosugi Maru／Anton／Bebas Neue／Archivo Black／Oswald／Poppins）から選択可能。また「対戦者名を太字にする」チェックボックスで太字ON/OFFを切替可能（勝者枠の名前は常に太字）。Anton・Bebas Neue・Archivo Black・Oswald・Poppinsは欧文（英数字）専用フォントのため、日本語文字は自動的にNoto Sans JPにフォールバックして表示される。管理画面・投影画面の両方に反映され、リアルタイム同期対象 |
| スナップショット保存・読込（ブラウザ内） | 左パネル最上部「保存・読み込み」セクションで、参加者名・カテゴリー・対戦の勝敗進行状況・デザイン設定（色・フォント・背景・ロゴなど）を丸ごと**このブラウザの`localStorage`内**に名前付きスナップショットとして複数保存可能。ファイルのダウンロード/アップロードは不要で、「現在の状態を保存」ボタン一つで保存でき、一覧から「読込」（上書き確認あり）・「削除」（削除確認あり）がワンクリックで行える。最大20件まで保存され、超過時は古いものから自動的に整理される |
| トーナメント表の画像保存（PNG・背景込み） | 「保存・読み込み」セクションの「トーナメント表を画像で保存」ボタンで、現在表示中のトーナメント表を、周囲の**ページ背景（背景色・背景画像）も含めた状態**でSVG→Canvas経由のPNG画像として書き出し、ブラウザからダウンロード可能。等倍の2倍解像度（Retina相当）で書き出され、ブラケットの周囲に余白を確保して背景がきちんと見える構図になる。SNSへの投稿や印刷、記録用のアーカイブなどにそのまま活用できる |

## 🌐 ページ構成

### `/index.html` — 管理画面 (Admin)
トーナメントの作成・管理を行うメイン画面

**操作フロー:**
1. 大会タイトルを入力
2. 参加人数（2〜64）を設定
3. 「トーナメント表を生成」をクリック
4. 参加者名を入力し「名前を反映」
5. トーナメント表の枠をクリックして勝者を選択
6. デザインパネルでプリセット（ライト/ダーク）を選択。より細かい調整をしたい場合は「詳細設定」を展開して色・透過度・対戦者名のフォント/太字をカスタマイズ
7. 「ページ背景」パネルでトーナメント表の周囲の背景色を選択、または「画像を設定」ボタンから背景画像をアップロード（画像は自動的にエリア全体に引き伸ばされて表示）。「画像を削除」でいつでも画像設定を解除可能
8. 「画像・ロゴ」パネルで大会ロゴや協賛ロゴ画像をアップロード。トーナメント表上の画像をマウスでドレグして位置を自由に移動、右下のハンドルをドレグしてリサイズ。リスト側ではレイヤー（前面/背面）や不透明度も調整可能
9. 「保存・読み込み」パネルで、参加者・対戦進行状況・デザイン設定などをまとめて「現在の状態を保存」ボタン一つでブラウザ内にスナップショットとして保存し、一覧から「読込」でいつでも復元、「削除」で不要なものを削除できる。また「トーナメント表を画像で保存」で現在のブラケットを背景込みのPNG画像としてダウンロードできる

### `/display.html` — 投影用表示画面
プロジェクターや大型モニター向けの表示専用画面

**操作:**
- マウスホバーでコントロールバーが表示
- `+` / `-` キーでズーム
- `0` キーで画面フィット
- `F` キーでフルスクリーン
- `R` キーで最新データに更新

## 🗃️ データ管理

- **保存先:** `localStorage` (`tournamentData` キー)
- **同期方式:** `BroadcastChannel('tournament_channel')`（同一ブラウザの複数タブ間）
- **フォールバック:** BroadcastChannel非対応時は1.5秒ポーリング

### データ構造

```json
{
  "tournament": {
    "numPlayers": 8,
    "total": 8,
    "rounds": [{ "matches": ["r0_m0", "r0_m1", ...] }],
    "matches": {
      "r0_m0": {
        "id": "r0_m0",
        "player1": { "name": "Player 1", "category": "hiphop", "isBye": false },
        "player2": { "name": "Player 2", "category": "lock", "isBye": false },
        "winner": null,
        "nextMatchId": "r1_m0"
      }
    }
  },
  "settings": {
    "title": "大会タイトル",
    "numPlayers": 8,
    "playerNames": ["Player 1", ...],
    "playerCategories": ["hiphop", "lock", ...],
    "colors": {
      "bg": "#000000",
      "bgOpacity": 1,
      "slot": "#000000",
      "slotWin": "#c6504c",
      "text": "#fdfdfd",
      "titleText": "#fdfdfd",
      "line": "#ffffff",
      "lineWin": "#c6504c",
      "border": "#ffffff",
      "borderWidth": 1.5
    },
    "displayWidth": {
      "enabled": false,
      "value": 1200
    },
    "pageBackground": {
      "color": "#0d0d1a",
      "imageDataUrl": null
    },
    "showCategory": true,
    "nameFont": "'Noto Sans JP', sans-serif",
    "nameBold": false,
    "logos": [
      {
        "id": "logo_1700000000000_ab12cd",
        "dataUrl": "data:image/png;base64,....",
        "layer": "front",
        "x": 24,
        "y": 24,
        "width": 80,
        "aspect": 0.35,
        "opacity": 1
      }
    ]
  },
  "updatedAt": 1700000000000
}
```

> `logos` の `layer` は `front`（ブラケットより前面）または `back`（背面・透かし）。`x`/`y` はSVG座標系上の左上座標で、管理画面上でのドレグ操作により更新されます。`width` はドレグリサイズで変更される表示幅（px）、`aspect` は画像の高さ÷幅の比率でアップロード時に自動計算されます。画像は静的サイトの制約上、base64の `data:` URLとしてLocalStorageに保存されます（1枚あたり4MBまで）。
>
> `settings.playerCategories` は各参加者のカテゴリー文字列を `playerNames` と同じ順番で保持する配列です。トーナメント生成時に各プレイヤースロットの `category` プロパティとして埋め込まれ、勝者引き上げ時にもオブジェクトのスプレッドコピーによって自動的に引き継がれます。カラープリセットにも `colors.titleText`（タイトル専用の文字色、未指定時は `colors.text` にフォールバック）が含まれます。
>
> `colors.border`／`colors.borderWidth` はプレイヤー枠を常時囲む境界線の色・太さです（勝者枠以外にも適用され、プレイヤー枠の塗り色が背景色と同色になっても境界線で枠の位置を判別できるようにするためのものです）。`colors.slotWin` は勝者になった枠の背景色、`colors.lineWin` は勝ち上がりを示す接続線の色で、それぞれ個別に設定できます。
>
> `settings.pageBackground` はSVGブラケット自体の背景（`colors.bg`）とは別に、トーナメント表を囲むページ上のエリア全体（管理画面の `#tournament-area`、投影画面の `#display-main`）に適用される背景設定です。`color` は背景色（16進カラーコード）、`imageDataUrl` は背景画像のbase64 `data:` URL（未設定時は `null`）です。画像が設定されている場合、`background-size: 100% 100%` によって縦横比を保たずエリア全体を埋めるように引き伸ばされて表示されます（アップロード時の画像サイズ制限：6MBまで）。管理画面での変更は即座にBroadcastChannel経由で投影画面にも反映されます。
>
> `settings.showCategory`（ブールtrue/false、デフォルト`true`）はブラケット上でカテゴリーを表示するかどうかのスイッチです。デザインパネルのプリセットボタン（☀️/🌙）の直下の「カテゴリーを表示する」チェックボックスで切替可能。OFFにしても `playerCategories` のデータ自体は削除されず、ブラケット上の表示のみがズされます（再度ONにすれば入力済みカテゴリーはそのまま復元）。管理画面・投影画面の両方に反映されます。
>
> **プレイヤー枠のレイアウト（カテゴリー表示位置）**：カテゴリーが設定されている場合、デフォルトでは「名前 (カテゴリー)」の形で名前の直後・同一行に小さめのフォントで表示されます。名前とカテゴリーを合わせた表示幅がプレイヤー枠の幅に収まらない場合は、自動的に2行表示（1行目：名前／2行目：カテゴリー）にフォールバックし、両方のフォントサイズも少し小さく調整されます。この判定はCanvas 2Dの`measureText`によるピクセル単位の実測に基づくため、フォントサイズやプレイヤー枠幅を変更しても正確に動作します。
>
> **優勝者バナーの表示位置・条件**：優勝者バナー（🏆 CHAMPION）は、タイトル直下のラウンドラベル行（準決勝・決勝など）のさらに下、ブラケット本体の上に表示されます。決勝の勝者が決定するまでは、バナー用のスペース自体を確保せず、プレースホルダーも一切表示しません（優勝者が決まった瞬間に自動的に表示されます）。
>
> `settings.nameFont`（文字列、デフォルト`"'Noto Sans JP', sans-serif"`）・`settings.nameBold`（ブールtrue/false、デフォルト`false`）は、ブラケット上の対戦者名（プレイヤー名）にのみ適用されるフォント・太字設定です。「デザイン」パネルの「詳細設定」内、BYE文字色の下にセレクトボックスとチェックボックスがあります。選択可能なフォント：Noto Sans JP（標準）、M PLUS Rounded 1c（丸ゴシック）、Kosugi Maru（丸ゴシック）、Anton（極太・英数字向け）、Bebas Neue（コンデンス・英数字向け）、Archivo Black（極太）、Oswald（コンデンス）、Poppins（ジオメトリック）。カテゴリー・BYE・未確定プレースホルダー・タイトル・ラウンドラベル・優勝者バナーの文字には影響しません（常にNoto Sans JP）。勝者になった枠の名前は `nameBold` の設定に関わらず常に太字で表示されます。管理画面・投影画面の両方に反映され、リアルタイム同期対象です。

## 💾 スナップショット保存・読み込み（ブラウザ内）／画像保存（PNG・背景込み）

管理画面の左パネル最上部にある「保存・読み込み」セクションから、ファイルのダウンロード/アップロードを行うことなく、**このブラウザの IndexedDB内**に状態を保存・復元できます。

### スナップショットの保存
任意で「スナップショット名」を入力し（未入力の場合は大会タイトルが使われます）、「現在の状態を保存」ボタンをクリックすると、現在の参加者名・カテゴリー・対戦の勝敗進行状況・タイトル・デザイン設定（色・フォント・ページ背景・ロゴなど）をすべて含むスナップショットが、ブラウザのIndexedDB（データベース名：`tournamentSnapshotDB`）に追加保存されます。保存は複数回行うことができ、一覧は保存日時の新しい順に並びます。最大保存件数は50件で、これを超えると古いスナップショットから自動的に削除されます。

> **保存先について（容量不足の対策）：** 以前のバージョンは `localStorage`（ブラウザごとに数MB程度しか使えない領域）に保存していたため、背景画像やロゴ画像を含むスナップショットを複数保存すると「保存容量が不足しています」というエラーが出ることがありました。現在は保存先を**IndexedDB**（数百MB〜それ以上の容量が使える領域）に変更しており、この問題は基本的に解消されています。以前 `localStorage` に保存されていたスナップショットがあれば、管理画面を開いた際に自動的にIndexedDBへ移行され、移行後は元の `localStorage` のデータは削除されます（移行は初回アクセス時に1回だけ行われます）。

```json
{
  "id": "snap_1700000000000_ab12cd",
  "name": "1回戦終了時点",
  "savedAt": 1700000000000,
  "tournament": { "...": "生成済みのトーナメント全データ（対戦組み合わせ・勝敗進行状況を含む）" },
  "settings": { "...": "デザイン設定・参加者名・カテゴリーなど（localStorageの settings と同一構造）" }
}
```

### スナップショットの読込・削除
保存したスナップショットは「保存・読み込み」セクション内の一覧に名前と保存日時付きで表示され、各項目には**テキスト付きの「読込」ボタンと「削除」ボタン**が並びます（アイコンのみでなく文字も表示されるため、操作対象が分かりやすくなっています）。「読込」ボタンから、確認ダイアログの後に現在の管理画面の内容（トーナメント表・参加者・デザイン設定すべて）がそのスナップショットの内容で上書きされます。「削除」ボタンから、確認ダイアログの後にそのスナップショットのみを削除できます（他のスナップショットは影響を受けません）。すべて削除すると「保存済みのスナップショットはありません」という案内が表示されます。

> **注意:** スナップショットは**このブラウザ（このPC・このブラウザアプリ）内のみ**に保存されます。別のPCやブラウザには自動的に引き継がれないため、ブラウザのデータ（サイトデータ／閲覧履歴）を消去すると失われます。

### トーナメント表を画像で保存（PNG・背景込み）
「トーナメント表を画像で保存」ボタンをクリックすると、現在表示中のトーナメント表（SVG）を、周囲の**ページ背景（背景色、および設定されていれば背景画像）も含めた状態**で、等倍の2倍解像度（Retina相当）のPNG画像に変換してダウンロードします（ファイル名例：`大会タイトル_2026-09-13.png`）。内部的には、まずCanvas全体をページ背景色で塗りつぶし、背景画像が設定されていればオンスクリーン表示と同じ `background-size: 100% 100%` 相当でキャンバス全体に引き伸ばして描画したうえで、その上に余白（パディング）を空けてブラケットSVGを重ねて描画し、`canvas.toBlob()` でPNG化しています。トーナメント表が生成されていない状態ではボタンを押すとエラートーストが表示されます。
